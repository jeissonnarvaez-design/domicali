# DomiCali

Plataforma de domicilios para Cali. Proyecto final de Estructuras de Datos II - UAO.

## Integrantes

- Sebastian Ocampo Ospina
- Jeisson Narvaez Preciado

## Correr el proyecto

```
npm install
ng serve
```

Las credenciales de Supabase van en `src/environments/environment.ts` y
`src/environments/environment.development.ts`.
